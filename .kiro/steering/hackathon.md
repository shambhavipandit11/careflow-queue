# Hackathon Sprint Rules (2.5-Hour Timebox)
- Tech stack: React 19, TypeScript, Vite, Tailwind CSS v4, lucide-react.
- Frontend-only architecture: Use `localStorage` + `BroadcastChannel` API for real-time cross-tab sync. Do NOT add a backend, database, or authentication.
- Do NOT write unit tests, Playwright tests, or Storybook files unless explicitly asked.
- Prioritize UI polish: modern healthcare SaaS aesthetic (`bg-slate-50`, elevated white cards, indigo-600 primary, emerald-500 active/called, amber-500 approaching, rose-500 urgent), smooth transitions, and mobile responsiveness.
